# visao_computacional
Para executar este projeto, é necessário:

- Ter o Python na versão **3.11.0** (versão ideal).
- Criar um ambiente virtual para instalar as dependências e rodar o código.
- Instalar as bibliotecas necessárias com o comando:

    ```bash
    pip install opencv-python mediapipe
    ```

Essas etapas garantem um ambiente isolado e compatível para o funcionamento do projeto.
