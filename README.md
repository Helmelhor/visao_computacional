# visao_computacional
Para executar este projeto, é necessário:

- Ter o Python na versão **3.11.0** (versão ideal).
- Criar um ambiente virtual para instalar as dependências e rodar o código.
- Instalar as bibliotecas necessárias com o comando:

    ```bash
    pip install opencv-python mediapipe
    ```

Essas etapas garantem um ambiente isolado e compatível para o funcionamento do projeto.

Como criar um ambiente virtual ? (power shell) 


iniciar

```powershell
python -m venv nome_do_ambiente
```

(criando com versão do específica do python)

```powershell
py -3.11 -m venv nome_do_ambiente
```

permissão termporaria caso não tenha permissão do adm

```powershell
Set-ExecutionPolicy RemoteSigned -Scope Process -Force
```

ativação do ambiente

```powershell
nome_do_ambiente\Scripts\activate
```
